# Naming
Status: Draft v0.1 · Owner: KhoiTran · Phase: all

This file records why the project is called Mnemo and what to check before any public release.

## Chosen name
**Mnemo** (decision D-014). It was called Bookmark Brain before. Pronunciation: NEE-moh. The name points to memory.

## Other candidates that were considered
Larder, Shelfmark, Linknest, Stashbox, Keepsake, Marginalia, Drawer, Tuck, Brainshelf, Tidemark, Engram, Noema, Brainmark, Linkmind, Sagemark, Memoria, Inkling, Lorebox, Foldwise.

Open question: availability of these names was not checked. Only Mnemo was checked.

## Finding: other software uses "mnemo"
Other software called mnemo exists:
- A note-taking app, listed on LinuxLinks and AlternativeTo.
- A tool on itch.io.
- An MCP server.

For a personal project this is fine. For a public release it can cause confusion and may cause legal problems. Open question: whether any of these names is a registered trademark. This was not checked and this file is not legal advice.
