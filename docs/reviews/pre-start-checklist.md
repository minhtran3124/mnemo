# Pre-Start Checklist
Status: Draft v0.1 · Owner: KhoiTran · Phase: 0

This file lists everything you need before phase 0. Tick each box. Nothing here is blocked by an open question.

## Tools
- [ ] Python is installed (Q-06: confirm Python is OK for you).
- [ ] Claude Code is installed and starts.
- [ ] Git is installed.
- [ ] A code editor or terminal you are comfortable with.

## Account and key
- [ ] You have an Anthropic Console account.
- [ ] You created an API key.
- [ ] The key is saved only in a password manager or in `.env`. Not in chat, not in notes.
- [ ] A monthly spending limit is set in the Console. Check the limit works (see [API notes](../reference/api-notes.md)).

## Repository
- [ ] A new folder named `mnemo/` exists.
- [ ] `git init` is done.
- [ ] `.gitignore` lists `.env` before the first commit (see [git and secrets](../process/git-and-secrets.md)).
- [ ] An empty `.env` file exists.
- [ ] `CLAUDE.md` exists with the rules: Python, plain files, never print the key.

## Input files
- [ ] 5 or 6 starter folders written in your own words (Q-02). Needed by phase 3, better now.
- [ ] [Sample links](../reference/sample-links.md) file is in the repo or nearby.

## Decisions to confirm
- [ ] D-013: accept `docs` and `other` types.
- [ ] D-016 and D-019: read them. V3 with light and dark is accepted.
- [ ] D-017: private mode, yes or no.
- [ ] Weekly API spend limit (Q-12).
- [ ] Sessions per week (Q-05).
- [ ] You know the targets in the [two-week test](../manual-testing/two-week-user-test.md) are proposals. Change them now.

## Policy
- [ ] You checked your company's AI policy before saving any work link (Q-13).
- [ ] You agree to save public links only while building (D-018).

## Docs read
- [ ] [Working agreements](../process/working-agreements.md)
- [ ] [Definition of done](../process/definition-of-done.md)
- [ ] [Phase 0 plan](../product/plans/phase-0-setup.md)
- [ ] [Decision log](../process/decision-log.md)
- [ ] [Open questions](../research/open-questions.md)

## Ready?
Phase 0 is ready to start when all boxes in Tools, Account and key, Repository and Policy are ticked. The other boxes can wait, but do not wait past phase 3.
