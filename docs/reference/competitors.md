# Competitors
Status: Draft v0.1 · Owner: KhoiTran · Phase: all

This file lists what already exists, so Mnemo does not compete where others are already good.

**Warning: only two pages were read for this table.** One page about Karakeep and one blog post about Pocket alternatives. The other apps were named in that post and their features were not checked. Check each app's own documents before you rely on this table.

## What exists

| App | What the sources say it does | What this means for Mnemo |
| --- | --- | --- |
| Karakeep (formerly Hoarder) | Open source. Saves links, notes, images and PDFs. Optional AI tags with OpenAI or a local Ollama model. Full-text search. Browser extensions and phone apps. Archives full pages so content survives a dead link. Rule-based auto-organization. | Do not rebuild extensions, phone apps or archiving. The page read does not mention answering questions in plain language, so that is a gap to test. |
| Pocket | Shut down, according to the blog post. The export tool went offline some months later, according to the same post. | Keep data in plain files you own, so no company can take it away. |
| Raindrop.io, Readwise Reader, Instapaper, Matter, Wallabag, GoodLinks | Named as alternatives in the same post. Features not checked. | Check one or two yourself. |

The blog post is promotional. Treat its numbers (about 2,847 saved links and about 94 read) as one example, not proof.

## Where Mnemo should be different
- Ask in your own words and get the link back with the reason you saved it.
- A weekly digest with what to read next, near-duplicates and dead links.
- The roast, which uses real numbers counted by code.
- Your data in plain files, searchable from Claude Code through an MCP server.
- Quality measured by an eval, not only by feeling.

## Honest advice
If you only want a good bookmark manager today, install one of these apps. Build Mnemo because it is yours, it teaches the course, and ask, digest and roast are where it can be different.

## Check yourself
Do these before phase 5. Write the answer in your session note.
1. Open the Karakeep documents. Can it answer a question in plain words? Does it show why you saved a link?
2. Try one more app from the list. Write down what it does with a link you cannot find again.
3. Check the export format of the app you pick. Can you get your data out in a plain file?
4. Check price and data policy for any app you would use instead.
5. Decide: does Mnemo still add something after this check?
